# 주택 수급 불균형과 가격 변동 연구

주택 공급통계(인허가·착공·준공)와 수요통계(인구·가구)를 결합해 **수급
불균형 → 가격 급등**의 시차 구조를 분석하고, **긴급 정책 개입이 필요한
경계지점(임계값)을 계산**하기 위한 연구 저장소.

## 구성

```
housing-research/
├── docs/
│   ├── 01_해외_방법론_서베이.md      # 해외 계량경제·AI 방법론 문헌 정리
│   ├── 02_시차_임계점_프레임워크.md   # 수급 시차·경계지점 계산 프레임워크 (수식/절차)
│   └── 03_비이성적_과열_한국_적용.md  # Shiller 비이성적 과열 이론과 한국 시장
├── src/housing_ews/                 # 분석 패키지
│   ├── pipeline.py     # 인허가→착공→준공 분포시차 추정·준공 전망
│   ├── demand.py       # 가구 기반 필요공급량
│   ├── gap.py          # 수급갭 (기간별·누적)

├── examples/
```

## 빠른 시작

```bash
pip install numpy pandas scipy statsmodels matplotlib
python examples/run_demo.py
```

데모는 합성 데이터로 다음을 수행한다.

1. **시차 추정**: 인허가→착공(평균 ~10개월, 실현율 87%), 착공→준공(평균
   ~30개월, 실현율 98%)의 분포시차를 비음최소제곱으로 복원
2. **준공 전망**: 향후 12/24/36개월 입주물량 전망 — 이미 관측된 인허가·
   착공만으로 결정된 비중(locked-in share)이 각각 100%/100%/98%임을 확인
   → **향후 2~3년 공급절벽은 지금 이미 계산 가능**
3. **수급갭**: 가구증가+멸실+공가버퍼 기반 필요공급 대비 수급률 산출
   (사후 지표와, 확정물량 기반 **선행 지표** 두 가지)
4. **과열 검정**: 실질가격 GSADF로 폭발적 상승 구간 시점 식별
5. **경계지점 계산**: 가격 급등 사건(실질 YoY 8%+)을 가장 잘 예보하는
   지표별 임계값을 신호접근법으로 역산
6. **경보 판정**: 4개 지표 가중 합성 → 정상/주의/경계/심각 4단계

## 핵심 산출물 (데모 기준)

| 지표 | 현재값 | 경계지점(임계값) | 판정 |
|---|---|---|---|
| 선행 수급률 (확정물량/필요, 12M) | 0.71 | ≤ 1.15 | 발령 |
| 사후 수급률 (준공/필요, 12M) | 0.83 | ≤ 0.89 | 발령 |
| GSADF 과열 여유폭 (BSADF−cv95) | +1.21 | ≥ −0.41 | 발령 |
| 실질가격 모멘텀 (6M 연율) | +0.25 | ≥ +0.04 | 발령 |

**종합 점수 1.00 → 심각(RED)**: 공급절벽(확정물량이 필요의 71%)과 가격
재가속이 동시에 진행 중인 상태 — 긴급 정책 개입 경계지점을 넘었다는 판정.
