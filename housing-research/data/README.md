# 실데이터 연결 가이드

데모는 합성 데이터(`examples/synthetic_data.py`)로 돌아간다. 실제 연구에서는
아래 통계를 월별 CSV로 내려받아 이 디렉터리에 두고, 데모의
`make_dataset()` 호출을 CSV 로더로 교체하면 된다.

## 필요한 시계열과 출처

| 시계열 | 출처 | 통계/경로 | 비고 |
|---|---|---|---|
| 인허가 (호) | 국토교통부 | 주택건설실적통계(인허가) — KOSIS 116호 / 국토교통 통계누리 | 아파트/비아파트, 시도별 분리 권장 |
| 착공 (호) | 국토교통부 | 주택건설실적통계(착공) | 2011년 이후 제공 |
| 준공(입주) (호) | 국토교통부 | 주택건설실적통계(준공) | 입주자모집(분양승인)도 보조지표로 유용 |
| 가구수 | 통계청 | 장래가구추계 (KOSIS) + 주민등록 세대수(행정안전부, 월별) | 추계는 연간 → 월별 보간; 세대수는 월별 실적 |
| 주택 재고 | 국토교통부/통계청 | 주택총조사 ·「주택보급률」 재고 통계 | 연간 → 월별 보간 |
| 멸실 (호) | 국토교통부 | 멸실주택 통계 | 없으면 재고×멸실률(연 0.3~0.6%) 근사 |
| 실질 가격지수 | 한국부동산원 / KB | 아파트 매매가격지수 ÷ 소비자물가지수(통계청) | 지역별(수도권/서울/지방) 분리 권장 |
| 가격/전세 비율 | 한국부동산원 / KB | 매매지수 ÷ 전세지수 (price-to-rent 대용) | GSADF 검정의 펀더멘털 대비 지표 |
| 소득 | 통계청 | 가계동향조사 가구소득 (분기) | price-to-income 계산용 |
| 금리 | 한국은행 ECOS | 기준금리, 주택담보대출 금리 | 수요 통제변수 |

## CSV 스키마

모든 파일은 다음 형식을 따른다 (월말 기준):

```csv
date,value
2011-01-31,31200
2011-02-28,28900
...
```

파일명 규약: `permits.csv`, `starts.csv`, `completions.csv`,
`households.csv`, `stock.csv`, `demolitions.csv`(선택), `price_real.csv`
(또는 `price_nominal.csv` + `cpi.csv`).

## 로더 예시

```python
import pandas as pd
from pathlib import Path

def load_series(name: str, data_dir: Path = Path("data")) -> pd.Series:
    df = pd.read_csv(data_dir / f"{name}.csv", parse_dates=["date"])
    s = df.set_index("date")["value"].asfreq("ME")
    return s.rename(name)
```

## 주의사항

- **아파트만 분리할 것**: 인허가→준공 시차는 아파트(24~36개월)와
  비(非)아파트(6~12개월)가 크게 다르다. 합산 시계열로 시차를 추정하면
  두 분포가 섞여 왜곡된다.
- **지역 분리**: 수도권과 지방의 수급 사이클은 위상이 다르다(2011~13
  지방 상승 vs 수도권 하락). 전국 합산은 신호를 상쇄시킨다.
- **착공 통계는 2011년 이후**: 그 이전 구간은 인허가→준공 단일 단계
  모형으로 대체하거나 표본에서 제외.
- **가구 추계 개편**: 통계청 장래가구추계는 주기적으로 개편되므로
  실시간 검증(real-time vintage) 시 당시 공표본을 써야 한다.
